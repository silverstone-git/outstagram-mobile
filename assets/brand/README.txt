# Outstagram logo set

Brand direction: dark, modern AI-learning platform; neon green + white on deep navy.

## Files
- `01-icon-gradient.svg` — transparent standalone symbol.
- `02-icon-dark-tile.svg` — symbol on a dark rounded tile.
- `03-horizontal-logo.svg` — primary horizontal lockup with tagline.
- `04-horizontal-no-tagline.svg` — horizontal lockup without tagline.
- `05-navbar-compact.svg` — compact navbar lockup.
- `06-horizontal-monochrome.svg` — single-color white wordmark lockup.
- PNG exports are included for quick previews and places that do not accept SVG.

## Colors
- Deep navy: `#0F1020`
- White: `#FFFFFF`
- Neon green: `#39F56B`
- Lime highlight: `#B7FF39`
- Muted lavender-gray: `#A8A9C7`

## Notes
SVG files are editable vector artwork. Wordmark text uses a system sans-serif fallback stack
(Inter, Manrope, Arial); for exact appearance across environments, convert text to outlines
in a vector editor after choosing/embedding your preferred font.
